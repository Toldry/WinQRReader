## Overview

Connecting a Windows 11 laptop to WiFi using QR codes generated by iOS (iPhone) or Android smartphones has historically been frustrating due to webcam fixed-focus limitations, screen glare, perspective distortion, and poor contrast.

**WinQRReader** solves this by pairing a multi-tier optical enhancement and QR decoding pipeline with a modern Windows 11 Fluent dark-theme desktop interface, providing instant recognition and one-click connection.

---

## Key Features

- **High-Performance QR Detection**:
  - **zxing-cpp**: High-speed C++ engine providing sub-millisecond barcode reading.
  - **Adaptive Optical Preprocessing**: Dynamic CLAHE contrast enhancement, dark-mode polarity inversion, and multi-scale center digital zoom with 2x cubic upscaling.
  - **OpenCV Fallback**: Secondary built-in decoder pass for edge cases.
- **Windows 11 Fluent UI**:
  - Dark-mode acrylic design matching Windows 11 aesthetics.
  - Real-time viewfinder with an animated HUD reticle and dynamic neon polygon tracking over recognized QR codes.
  - Camera device selector with hot-refresh support.
- **One-Click Native WiFi Connection**:
  - Automatically generates valid Windows Native WLAN XML profiles (`v1` schema).
  - Supports **WPA3-Personal (SAE)**, **WPA2-Personal (AES)**, **WPA-Personal (TKIP)**, **WEP**, and **Open** networks.
  - Handles hidden SSIDs and special character escaping (`&`, `<`, `>`, `"`, `\`, `;`, etc.).
  - Background connection worker with real-time status updates and rollback on timeout.
- **Privacy & Security**:
  - Passwords masked with bullets by default.
  - One-click reveal toggle and copy to clipboard.
  - All processing runs 100% locally on your device with zero cloud dependency.
- **Universal QR Support**:
  - Gracefully detects non-WiFi QR codes (URLs, plain text) with quick copy and "Open Link" browser integration.

Double-click `run.bat` in the project root directory. It will automatically check dependencies and launch the application.

```bat

```

### 2. Manual Python Execution

```powershell
# 1. Install dependencies
python -m pip install -r requirements.txt

# 2. Run application
python main.py
```

## How to Use

1. **Launch the App**: Open WinQRReader.
2. **Activate Camera**: Click the **Activate Camera** button to start the live video feed.
3. **Scan the WiFi QR Code**:
   - Open the WiFi sharing QR code on your phone (e.g. *Settings > Wi-Fi > Share Network* on Android or *Shortcuts / WiFi QR* on iPhone).
   - Hold your phone screen about 20–30 cm (8–12 inches) in front of the laptop webcam.
   - Tip: Tilt the screen slightly to avoid overhead light glare reflecting into the webcam lens.
4. **Review & Connect**:
   - The scanner instantly locks onto the QR code with a neon bounding box and pauses the camera.
   - The **Network Details Card** appears with the SSID, security type (e.g., `WPA2-Personal`), and masked password.
   - Click **Connect to WiFi** to connect your laptop to the network automatically.
   - Alternatively, click the copy button to copy the password to your clipboard.
5. **Scan Another**: Click **Scan Another Code** to resume the live viewfinder.

## Creating a Standalone Windows Executable (.exe)

You can compile WinQRReader locally into a standalone, portable Windows application that runs without Python installed:

```powershell
python build_exe.py
```

The output will be created in `dist/WinQRReader/WinQRReader.exe`.

## Troubleshooting

- **Camera Not Found**: Ensure camera permissions are granted in *Windows Settings > Privacy & security > Camera*, or click the refresh button in the header.
- **Connection Timed Out**: Ensure the WiFi access point is within wireless range of your laptop and that your WiFi adapter is enabled.
